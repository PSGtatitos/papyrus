# Papyrus roadmap

## Papyrus 2.0 candidates

- **Smart Auto-Pause (resource control):** current adapters cover Sway, Hyprland, and X11/EWMH sessions; fullscreen apps trigger pause on those backends. COSMIC and other Wayland desktop adapters remain future work because there is no sufficiently capable universal Wayland window-state API yet.
- **Library tools:** implemented search by name/folder, type and active-state filters, and sorting by name/date/size.
- **Fedora distribution:** Papyrus and mpvpaper RPM specs plus COPR instructions are prepared. Create and publish the COPR project to make it installable with DNF.
- **Explore tab (deferred):** provider choice and access rules will be considered later. Wallhaven was removed from the app; MotionBGs remains a future research option.

The frosted-glass fallback and selectable in-app backdrop are already available and are not pending 2.0 work.
